# Sticky:
    Header de StackBlizt, pueden usar el que ya arme en clase.
    Debe perseguirte por la pagina al scrollear verticalmente.
    URL: https://stackblitz.com/


Recomendaciones: 

- Lo proritario es el uso de position, osea si no le das a la fuente, color o icono no importa, mientras el position funcione bien es correcto.
- Position tiene que ser una herramienta que se usa con prudencia, es decir, si podes usar flexbox o tenes una forma de hacerlo con flexbox, siempre elegi flexbox. Position es el ultimo recurso, solo usarlo cuando realmente lo necesitas. (Esto es asi, porque position es muy dificil hacerlo responsivo)
